# 🚀 دليل رفع التحديث على GitHub

1. قم بإنشاء مستودع (Repository) عام على GitHub (مثلاً: VocabMaster).
2. ارفع مجلد updates (أو ملف ersion.json وملف update.zip) إلى المستودع.
3. انسخ رابط الـ Raw لملف ersion.json من GitHub، وسيكون بالشكل التالي:
   https://raw.githubusercontent.com/اسم_حسابك/اسم_المستودع/main/updates/version.json

4. افتح ملف ersion.json وضع فيه رابط الـ Raw لملف update.zip أيضاً.
5. في التطبيق، افتح شاشة التخزين والنسخ الاحتياطي والصق رابط ersion.json واضغط حفظ!
6. من الآن فصاعداً: كلما أردت إرسال تحديث للمستخدمين، فقط ارفع update.zip الجديد وغيّر رقم الإصدار في ersion.json إلى (1.2.0 مثلاً)، وسيتحدث التطبيق عند الجميع تلقائياً وبشكل فوري!
